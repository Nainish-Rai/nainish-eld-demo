# Spotter AI Frontend

The frontend README is intentionally thin because the assessment entry point is the root [`README.md`](../README.md).

Use this folder for the React + Vite planner workspace:

```bash
cp .env.example .env
npm install
npm run dev
```

The app expects the Django API at `VITE_API_BASE_URL`, defaulting to `http://localhost:8000/api`.
